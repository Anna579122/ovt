PROFESIJU VIEDLAPA — HTML sākuma projekts

Faili:
- index.html — sākumlapa ar profesiju iniciāļiem
- mt.html, vp.html, vd.html u.c. — atsevišķas profesiju lapas
- styles.css — kopīgais dizains visām lapām

Kā apskatīt:
1. Atarhivē ZIP failu.
2. Atver index.html pārlūkā (Chrome, Firefox u.c.).
3. Nospied uz iniciāļiem — atvērsies attiecīgā profesijas lapa.

Kā pielāgot:
- Katrā [kods].html failā nomaini [Ieraksti profesijas nosaukumu] un parauga tekstus.
- Fotogrāfiju vietā ievieto savus attēlus, piemēram:
  <img src="images/foto1.jpg" alt="Audzēkņi mācību procesā">
- Ja maini dizainu, rediģē styles.css.
- Sākumlapā profesiju kartīšu secību un iniciāļus vari mainīt index.html.

Pirms publicēšanas:
Visiem failiem jāatrodas vienā mapē. Augšupielādē visu mapes saturu tīmekļa hostinga servisā.
